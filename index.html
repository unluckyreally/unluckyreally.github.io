Known limitations
·
No NER. The features has_person and has_work_of_art are always 0 here — they need spaCy's named-entity recogniser which cannot run in a browser. The model was trained with spaCy, so those two dimensions may underweight some queries.
·
Training data size. The model was trained on the same test split used for evaluation. With a small dataset this risks overfitting, and the decision boundary may not generalise well to query styles outside the training set.
·
Surface features only. Classification relies on hand-crafted lexicons (hedge words, genre words, negation, etc.). A query can be genuinely hard to retrieve without containing any of these signals, and vice versa.
·
Low threshold (0.21). The threshold is tuned for high recall of hard queries (F₂ optimisation), so the classifier leans toward labelling ambiguous queries as hard. This reduces missed hard cases but increases false positives.
·
Domain specificity. The model is trained on Tip-of-the-Tongue queries (movies, books, songs, words). It will likely misclassify queries from other domains.
